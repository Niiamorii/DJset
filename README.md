## Test audio GitHub et VizVid

Le fichier `DJSet_Test_Lecture_GitHub_20261011.mp3` est un son synthetique original
cree pour verifier la lecture d'un MP3 heberge sur GitHub dans VizVid.
Il ne contient aucun extrait du jeu DJ Set.

- Duree du signal : 8 secondes.
- Format : MP3 stereo, 44,1 kHz, 128 kbit/s.
- Lecteur a utiliser dans VizVid : AVPro.
- La lecture doit etre verifiee dans VRChat sur PC puis sur Quest autonome.
- La compatibilite GitHub/VizVid/Quest n'est pas encore confirmee.

La Release `test-v1` doit fournir ce fichier comme piece jointe.
